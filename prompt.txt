# 1. Project Objective

SmartCar is a machine learning web application that predicts the estimated resale price of a used car based on its specifications and usage history.

Users should be able to:
- Enter vehicle details through an interactive form.
- Receive an estimated selling price in Indian Rupees (₹).
- Understand the prediction through a visually clear result section.
- Explore car price analytics.
- View their previous prediction history.

The application must use the uploaded trained model for actual predictions.

Do not generate fake predictions or hardcode sample prediction values.

The model input features include:

- seller_type
- transmission
- owner
- mileage
- engine
- max_power

The `car_age` feature is derived from the manufacturing year using the notebook's reference year of 2026.

## Model integration rules

1. Load the existing model from `smartcar_best_model.joblib`.
2. Do not retrain the model unnecessarily.
3. Do not replace the uploaded model with a different algorithm.
4. Do not modify the original model file.
5. Preserve the trained preprocessing pipeline.
6. Pass the prediction input in the correct feature format and column structure expected by the model.
7. Use a Pandas DataFrame for model inference if required by the saved pipeline.
8. Handle missing values and categorical values according to the trained pipeline.
9. Calculate car age consistently with the notebook.
10. Verify that model inference works correctly before connecting the frontend.

The uploaded model was serialized with Scikit-learn 1.6.1. Use a compatible backend environment, preferably pinning Scikit-learn to 1.6.1, and verify that the model loads and predicts successfully. If compatibility issues arise, diagnose them rather than silently replacing the model.
